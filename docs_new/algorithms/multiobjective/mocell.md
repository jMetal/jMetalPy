# MOCell

[MOCell](https://doi.org/10.1016/j.compeleceng.2008.06.003) is a cellular genetic algorithm: the
population is arranged on a toroidal grid, and each individual only interacts with its immediate
neighbors, which promotes diversity through structured, localized selection.
