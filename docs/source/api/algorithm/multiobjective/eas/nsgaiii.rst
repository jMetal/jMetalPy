NSGA-III
========

`NSGA-III <https://doi.org/10.1109/TEVC.2013.2281535>`_ extends NSGA-II to many-objective
problems: instead of the crowding distance, it uses a set of predefined reference directions to
guide selection and maintain diversity in high-dimensional objective spaces.
