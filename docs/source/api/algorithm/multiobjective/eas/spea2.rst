SPEA2
=====

`SPEA2 <https://doi.org/10.3929/ethz-a-004284029>`_ (Strength Pareto Evolutionary Algorithm 2)
assigns each individual a strength-based fitness that accounts for both dominance and density,
and uses an external archive to keep the best solutions found across generations.
