IBEA
====

`IBEA <https://doi.org/10.1007/978-3-540-30217-9_84>`_ (Indicator-Based Evolutionary Algorithm)
uses a binary quality indicator (additive epsilon, by default) to guide environmental selection,
instead of Pareto dominance and a density estimator.
