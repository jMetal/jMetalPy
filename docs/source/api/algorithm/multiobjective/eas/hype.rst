HYPE
====

`HYPE <https://doi.org/10.1162/evco.2011.19.1.19103>`_ is a hypervolume-indicator-based
evolutionary algorithm: it uses exact hypervolume contribution to rank and select solutions,
which makes it accurate but computationally expensive on larger populations or evaluation
budgets.
