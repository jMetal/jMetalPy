OMOPSO
======

`OMOPSO <https://doi.org/10.1007/3-540-36970-8_59>`_ is a particle swarm optimization algorithm
for multi-objective problems, using an epsilon-dominance archive and uniform/non-uniform mutation
to balance convergence and diversity.
