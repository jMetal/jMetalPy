Observer
========

The ``Observer``/``Observable`` interfaces live in :py:mod:`jmetal.core.observer`; the concrete
observers algorithms are typically run with (progress bars, live plotting, writing results to
disk, ...) live in :py:mod:`jmetal.util.observer`. See :doc:`/tutorials/observer` for usage
examples.
